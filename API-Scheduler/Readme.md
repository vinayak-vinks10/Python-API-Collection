This project is a simple API Scheduler built using Python. It allows users to schedule API calls at specific times and automatically sends requests in the background using multithreading. The idea behind this project was to understand how APIs work in real-world scenarios and how tasks can be automated based on time.

The project also includes a basic user interface built with Streamlit, making it easy to add and manage tasks without using the command line. Each task takes a URL and a time, and the system handles the rest, including retrying failed requests and logging results.

Key features:

Schedule API calls at specific times
Supports multiple tasks using threading
Retry mechanism for failed API requests
Logs all activity in a file
Optional feature to open the URL in a browser after success
Simple and clean UI using Streamlit

This project helped in learning concepts like API handling, multithreading, scheduling, and basic UI integration in Python. It is designed to be simple, readable, and easy to explain, making it a good practice project for understanding real-world use of APIs.
